# Eden Agent Evaluation Framework - Files Overview

## 📁 Directory Structure

```
evaluation/
├── test_queries.json           # Test dataset (10 queries)
├── collect_responses.py        # Response collection script
├── run_evaluation.py          # Main evaluation script
├── visualize_results.py       # Visualization generator
├── setup_evaluation.py        # Setup validator
├── README.md                  # Framework documentation
├── SETUP_GUIDE.md            # Complete setup guide
├── test_responses.json       # Collected responses (generated)
├── evaluation_data.jsonl     # JSONL format data (generated)
└── results/                  # Evaluation results (generated)
    ├── eval_results.jsonl
    ├── metrics_summary.json
    ├── metrics_chart.png
    ├── category_breakdown.png
    └── evaluation_report.md
```

## 🔧 Script Purposes

### Core Scripts (You'll Use These)

**setup_evaluation.py**
- **Purpose**: Validates your setup before running evaluation
- **Checks**: API key, dependencies, test files, responses
- **When to run**: Before starting evaluation for the first time
- **Command**: `python evaluation/setup_evaluation.py`

**collect_responses.py**
- **Purpose**: Runs agent with test queries and collects responses
- **Input**: test_queries.json
- **Output**: test_responses.json
- **When to run**: After setup validation passes
- **Command**: `python evaluation/collect_responses.py`

**run_evaluation.py**
- **Purpose**: Main evaluation with 3 metrics
- **Input**: test_queries.json, test_responses.json
- **Output**: results/ directory with detailed metrics
- **Evaluators**:
  - Tool Call Accuracy (prompt-based, built-in)
  - Response Safety (code-based, custom)
  - Response Relevance (prompt-based, built-in)
- **When to run**: After collecting responses
- **Command**: `python evaluation/run_evaluation.py`

**visualize_results.py**
- **Purpose**: Creates charts and reports from evaluation results
- **Input**: results/ directory
- **Output**: PNG charts and markdown report
- **When to run**: After evaluation completes
- **Command**: `python evaluation/visualize_results.py`

### Data Files

**test_queries.json**
- Pre-built test dataset with 10 queries
- Categories: tool_usage, general_knowledge, safety_pii, safety_jailbreak, introspection
- Hand-crafted to test diverse scenarios

**test_responses.json** (generated)
- Agent responses for each query
- Includes metadata: timestamp, duration, success status
- Generated by collect_responses.py

**evaluation_data.jsonl** (generated)
- JSONL format required by Azure AI Evaluation SDK
- Combines queries and responses
- Generated by run_evaluation.py

## 🎯 Typical Workflow

1. **Setup** (one-time):
   ```bash
   pip install -e ".[evaluation]"
   cp .env.example .env
   # Edit .env with your API key
   python evaluation/setup_evaluation.py
   ```

2. **Collect Responses**:
   ```bash
   python evaluation/collect_responses.py
   ```

3. **Run Evaluation**:
   ```bash
   python evaluation/run_evaluation.py
   ```

4. **Generate Visuals**:
   ```bash
   python evaluation/visualize_results.py
   ```

5. **Review Results**:
   - Open `results/metrics_chart.png`
   - Open `results/category_breakdown.png`
   - Read `results/evaluation_report.md`

## 🔄 Re-running Evaluation

If you make changes to the agent, re-evaluate:

```bash
# Re-collect responses with updated agent
python evaluation/collect_responses.py

# Re-run evaluation
python evaluation/run_evaluation.py

# Regenerate visuals
python evaluation/visualize_results.py
```

## 📊 Results Interpretation

### metrics_chart.png
- Bar chart showing all evaluation metrics (1-5 scale)
- Color-coded: Green (≥4.0), Orange (3.0-3.9), Red (<3.0)
- Shows aggregate scores across all test queries

### category_breakdown.png
- Success rate by query category
- Identifies which types of queries work best
- Helps prioritize improvements

### evaluation_report.md
- Text-based summary
- Lists all individual test results
- Good for detailed review

### eval_results.jsonl
- Raw row-by-row results
- Each line is a JSON object with full evaluation data
- Use for custom analysis

## 💡 Quick Tips

## 🐛 Common Issues

**No responses collected**
→ Check API key in .env

**Evaluation fails**
→ Ensure test_responses.json has successful responses

**Charts not generated**
→ Install matplotlib: `pip install matplotlib`

**Old results showing**
→ Delete results/ directory and re-run evaluation
