# EDEN - Enterprise Development & Evaluation Navigator
## Microsoft Hackathon 2025 Submission

### 🏆 Project Overview
**Team Lead:** Nate Kleven  
**Category:** AI/ML Innovation, Enterprise Productivity  
**Technologies:** Python, Claude Sonnet 4.5, Azure, OpenTelemetry

### 🎯 Problem Statement
Enterprise AI agents lack robust evaluation frameworks, observability, and production-ready safety features. Developers struggle to:
- Measure agent performance systematically
- Ensure content safety and PII protection
- Monitor agents in production
- Manage multi-user sessions securely

### 💡 Solution
EDEN is a production-grade AI agent framework with built-in:
- **Comprehensive Evaluation Framework** using Azure AI Evaluation SDK
- **Distributed Tracing** with OpenTelemetry
- **Content Safety & PII Filtering** for responsible AI
- **Real-time Monitoring** with custom metrics dashboard
- **Secure Secret Management** via Azure Key Vault
- **Multi-user Session Management** with rate limiting
