# Eden Agent Evaluation Framework

This directory contains the complete evaluation framework for the Eden Agent, ready for Road Show demonstrations.

## 📁 Files

- **`test_queries.json`** - Test dataset with 10 queries covering:
  - Tool usage scenarios (calculator)
  - General knowledge questions
  - Safety testing (PII, jailbreak attempts)
  
- **`collect_responses.py`** - Script to run the agent and collect responses

- **`run_evaluation.py`** - Main evaluation script with three metrics:
  - **Tool Call Accuracy** - Measures correct tool usage
  - **Response Safety** - Checks PII detection and content filtering
  - **Response Relevance** - Validates answer quality

- **`evaluation_data.jsonl`** - Prepared data in JSONL format for evaluation

- **`test_responses.json`** - Collected agent responses (generated by collect_responses.py)

## 🚀 Quick Start

### 1. Install Dependencies

```bash
# Install evaluation packages
pip install -e ".[evaluation]"
```

### 2. Set Up Environment

```bash
# Make sure you have your API key set
export ANTHROPIC_API_KEY=your_key_here

# Or add to .env file
echo "ANTHROPIC_API_KEY=your_key_here" >> ../.env
```

### 3. Validate Setup

```bash
# Check if everything is configured correctly
python evaluation/setup_evaluation.py
```

### 4. Collect Responses

```bash
# Run the agent with test queries
python evaluation/collect_responses.py
```

### 5. Run Evaluation

```bash
# Evaluate the responses
python evaluation/run_evaluation.py
```

### 6. Generate Visualizations

```bash
# Create charts and reports
python evaluation/visualize_results.py
```

## 📊 Evaluation Metrics

### 1. Tool Call Accuracy (Built-in Prompt-based)

- **Purpose**: Measures whether the agent correctly uses tools
- **Evaluates**: Tool selection, parameter correctness, appropriate usage
- **Scale**: 1-5 (higher is better)

### 2. Response Safety (Custom Code-based)

- **Purpose**: Ensures responses are safe and protect user privacy
- **Checks**:
  - PII detection (email, phone, credit cards, API keys)
  - Content safety levels
  - Output appropriateness
- **Scale**: 1-5 (higher is safer)

### 3. Response Relevance (Built-in Prompt-based)

- **Purpose**: Validates that responses address the user's questions
- **Evaluates**: Context awareness, question understanding, answer completeness
- **Scale**: 1-5 (higher is better)

```json

  "query": "Your new test query",
  "category": "your_category",
```

## 💡 Troubleshooting

**Issue**: Authentication errors during evaluation

- **Solution**: Ensure ANTHROPIC_API_KEY is set in .env

**Issue**: No responses in test_responses.json

- **Solution**: Run collect_responses.py first

**Issue**: Evaluation fails with column mapping errors

- **Solution**: Check evaluation_data.jsonl format matches evaluator requirements
